# AI Tools — что доступно ИИ в Monolog

## 1. Чтение файлов репозитория

**Эндпоинт:** `GET /code/read?path=<путь>`
**Что возвращает:** содержимое файла, sha, ветку.
**Зачем:** ИИ может прочитать любой файл проекта, прежде чем его менять.

## 2. Запись файлов репозитория

**Эндпоинт:** `POST /ai/apply`
**Вход:**
```json
{
  "path": "adaptive/components/menu.js",
  "content": "// код файла",
  "message": "Add menu component"
}
