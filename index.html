Ключ API
Данные хранятся только на вашем устройстве. Диалоги, документы и ключи не уходят на сервер. Ключ передаётся только для соединения с моделью.
Ключ автора
Одно поле для двух ключей. Если ключ открывает только блог — доступен блог. Если ключ открывает Управление — доступно всё.
Режим глубины
Регулирует глубину диалога и переключает тему приложения.
Данные
Все данные живут в вашем браузере (IndexedDB). Мы не храним их на сервере. Чтобы не потерять — делайте экспорт. Импорт восстановит из файла.
