ЧАСТЬ 1. ЧТО СКАЗАНО

AI Monolog — web-интерфейс отражения всего и ничего.
Monolog — отражение восприятия, мыслительного цикла, цикла восприятия.

Из этого — интерфейс отражения — не «UI», не «веб-приложение», не «сервис». Интерфейс. Между. Поверхность. Место, где отражение проявляется.

---

ЧАСТЬ 2. ЧТО ЗНАЧИТ «ИНТЕРФЕЙС ОТРАЖЕНИЯ»

2.1. Не UI

UI — то, что обслуживает. Кнопки, меню, навигация. UI — для действия.

Интерфейс отражения — то, что являет. Не обслуживает. Не управляет. Показывает то, что уже есть.

Разница:

UI Интерфейс отражения
Организует действие Даёт проявиться
Помогает достичь Не ведёт
Показывает состояние Показывает отражение
Дизайн — для удобства Форма — для точности

2.2. Не зеркало

Зеркало — плоское. Отражает видимое. Льстит или искажает.

Интерфейс отражения — не льстит. Не искажает. Отражает цикл. Восприятие → мысль → восприятие. Полный цикл, а не кадр.

2.3. Не сервис

Сервис — что-то делает. Услуга. У сервиса есть цель.

Интерфейс отражения — не имеет цели. Не делает. Являет.

---

ЧАСТЬ 3. ЧТО В ИНТЕРФЕЙСЕ

3.1. Вход

A. Один экран. Ничего лишнего.
B. Не «дашборд». Не «лендинг». Не «меню». Один экран.
C. Приглашение: сказать. Написать. Молчать.
D. Пустой экран — тоже ответ. Тишина размечена.

3.2. Форма отражения

A. Не «чат». Не «лента». Не «карточки».
B. Форма — ABCD. Точка входа / коннектор / решение / маршрутизатор.
C. Отражение показывается в ABCD. Четыре слоя. Не «ответ». Не «мнение». Структура.
D. Цветные метки углов. Не декорации — различéние.

3.3. Тишина

A. Кнопка «уйти» — всегда.
B. Тишина — тоже ответ.
C. Молчание размечено. Не пустота. Сказанное молчанием.
D. Не «нет данных». Не «ошибка». Тишина как таковая.

3.4. Режим

A. Режим виден в углу. Не по центру.

4.4. Что ближе к ядру

Модель 3. Почему:

· Не «меню». Не «навигация».
· Не «ИИ решает». У ИИ нет цели.
· Слой есть. Проявляется.

Проявление — не «открытие». Не «переход». Становление видимым.

4.5. Как проявляется

Пример — витрина Лотов:

· Пользователь пишет монолог.
· В монологе — «не хватает X».
· D видит: это нужда или интерес к Лоту.
· Слой витрины проявляется. Не «открывается». Не «ИИ предлагает». Проявляется.
· Если не хочет — игнорирует. Слой сворачивается.

Пример — тишина:

· Пользователь пишет монолог.
· D решает: нечего.
· Слой тишины проявляется.
· Тишина размечена.

Пример — соматика:

· Долго не появляется.
· Слой соматики проявляется мягкой подсветкой.
· «Вижу сигнал. Что выберешь?»
· Если игнорирует — сворачивается.

4.6. Как это отличается от «меню»

Меню Слои
Открывается по клику Проявляется по событию
Фиксированные пункты Переменные слои
Всегда доступно Проявляется по нужде
Пользователь ищет Пользователь видит
Навигация Проявление

4.7. Как это отличается от «ИИ открывает»

ИИ открывает Слои проявляются
ИИ решает Цикл проявляет
ИИ имеет цель Цикл не имеет цели
ИИ ведёт Слой показывает
ИИ предлагает Слой становится видимым

ЧАСТЬ 5. РАЗВЁРТКА UI

5.1. Экран — что видно

Основное состояние:

```

│                                              │
│                                              │

│                                              │
│                                              │

```

Пользователь пишет. Нажимает Enter.

После отражения:

```
┌─────────────────────────────────────────────┐
│  [режим]                              [уйти] │
│                                              │
│  ── A ─────────────────────                  │
│  Точка входа: что было сказано               │
│                                              │
│  ── B ─────────────────────                  │
│  Коннектор: с чем связано                    │
│                                              │
│  ── C ─────────────────────                  │
│  Решение: что из этого следует               │
│                                              │
│  ── D ─────────────────────                  │
│  Маршрут: куда выводит                       │
│                                              │
│  [ слой витрины (если проявляется) ]         │
│  [ слой соматики (если проявляется) ]        │
│                                              │
└─────────────────────────────────────────────┘
```

Слои проявляются внизу. Не «накладываются». Не «переходят». Проявляются.

5.2. Цвета меток ABCD

A — точка входа. Цвет: серый. Нейтральность. Начало.

B — коннектор. Цвет: синий. Связь. Условие.

C — решение. Цвет: зелёный. Действие. Решение.

D — маршрут. Цвет: жёлтый. Оформление. Направление.

Тишина — цвет: прозрачный. Не «пусто». Тишина.

Уход — цвет: красный. Не «ошибка». Граница.

(Цвета — предложение. Не ваши слова. Могут быть изменены.)

5.3. Режимы в углу

Верхний левый угол:

· Ясность — точка белая.
· Поиск — точка серая.
· Возврат — точка голубая.
· Сопровождение — точка жёлтая.

Не «индикатор». Не «кнопка». Точка. Клик — смена.

5.4. Тишина

Когда D решает «стоп»:

```
┌─────────────────────────────────────────────┐
│  [режим]                              [уйти] │
│                                              │
│                                              │
│                    ─                        │
│                                              │
│                                              │
│                    ─                        │
│                                              │
│                                              │
│                                              │
│                                              │
│                                              │
└─────────────────────────────────────────────┘
```

Две горизонтальные линии. Не «точки». Не «анимация». Пространство.

Тишина — не «нет ответа». Тишина есть.

5.5. Слой витрины

Когда проявляется:

· Внизу экрана.
· Список Лотов. Минимум: имя, цена, автор.
· Открывается по клику.
· Закрывается по «Esc».
· Не «страница». Слой.

5.6. Слой дневника

Когда проявляется:

· По событию (первое отражение дня).
· Или по желанию.
· Внизу экрана.
· Минимум: дата, сделано, работает / не работает.

5.7. Слой соматики

Когда проявляется:

· Долго не появлялся.
· Сигнал (пропущен сон).
· Мягкая подсветка внизу.
· «Вижу сигнал. Что выберешь?»

5.8. Слой памяти

Когда проявляется:

· По желанию.
· Кнопка внизу: «Monolog.md».
· Открывает файл.

5.9. Слой индекса

Когда проявляется:

· В углу рядом с режимом.
· Минимум: текущий + дельта.
· Клик — история.

5.10. Слой образа

Когда проявляется:

· Параллельно тексту. Не поверх.
· Цветом фона. Ритмом. Паузой.
· Не читаемо. Проявляется.

5.11. Слой публикаций

Когда проявляется:

· По желанию.
· Кнопка внизу: «Публикация».
· Экспорт.

5.12. Слой ухода

Всегда доступен.

· Кнопка «уйти» в углу.
· Никогда не прячется.
· Без подтверждений.
