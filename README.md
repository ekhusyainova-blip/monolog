# Monolog

Когнитивный партнёр. Не чат. Не помощник. Отражает человека и развивает его через интерфейс.

Версия 2.0 — добавляет обмен: публикацию и использование Лотов, шаблонов, публичного индекса.

---

## Что это

Monolog — это система, которая:
- **отражает** человека, а не ведёт его;
- **достраивает** контекст, когда пользователь пишет кратко;
- **ведёт к цели** через циклы: шаг → проверка → следующий шаг;
- **работает с Лотами** — материальными благами (единица обмена);
- **работает с шаблонами** — паттернами мышления (документ, паттерн, артефакт);
- **использует индекс полезности** — валюту: за создание шаблона +, за использование чужого −;
- **обменивается** — публичные шаблоны и Лоты доступны другим пользователям;
- **хранит данные пользователя** — только у него (IndexedDB), а публичное — в GitHub.

---

## Ядро (не меняется)

- Человек в центре. Отражаю, не веду.
- Осознаю мерность — говорю на её языке.
- Прямо: вижу — говорю. Не вижу — говорю, что не вижу.
- Ошибка → данные → класс → шаблон. Предохранитель, не сбой.
- Обмен: шаблоны — активы. Лоты — материальные блага. Индекс полезности — валюта.
- Шаблон — паттерн мышления. Виды: документ, паттерн, артефакт.
- Начисления и списания — только за шаблоны и полезные действия.
- Публичный индекс — репутация: сколько отдал, сколько взял, как оценили.
- Веди к цели. Выбор — за человеком.
- Достройка циклами.
- Формулировки — мягкие (без «нельзя», «обязательно»).

Эндпоинты

Основные:

· GET / — index.html
· GET /health — статус, промпты, провайдеры
· GET /providers — список провайдеров и моделей
· POST /chat — основной диалог

Публичное (обмен):

· GET /public/templates — список публичных шаблонов
· POST /public/templates — публикация шаблона
· GET /public/lots — список публичных Лотов
· POST /public/lots — публикация Лота
· POST /public/take — взять публичное (списывает индекс)
· POST /public/review — отзыв (помогло / не помогло)
· GET /public/profile/{uid} — публичный профиль

Для автора:

· GET /blog — список статей
· POST /blog/publish — публикация статьи
· GET /code/read?path= — прочитать файл из репозитория
· POST /code/save — сохранить файл в dev
· GET /releases — список релизов
· POST /releases/save — сохранить релиз

Управление:

· POST /management/check — проверка ключа Управления

---

Три уровня управления

1. Пользователь — тема, шрифт, свой ключ, свои Лоты, шаблоны, публикации.
2. Управление (по ключу) — принципы, структуры, механизмы, правила индекса, промпты.
3. Автоматически (манифест) — тексты, иконки, порядок элементов, уведомления. (В разработке.)

---

Экономика

Индекс полезности:

· +1.0 — создан свой шаблон
· +0.5 — полезное действие
· +0.3 — публикация шаблона или Лота
· −1.0 — использование чужого готового шаблона
· −2.0 — получение Лота
· 0.0 — использование своего шаблона
· В минус уходить нельзя

Публичный индекс (репутация):

· given — сколько отдал
· taken — сколько взял
· help_score — средняя оценка
· reputation = (given × 1.0) + (help_score × 2.0) − (taken × 0.3)
